# AURA

AURA (Autonomous Unified Reel Assistant) is a production-oriented monorepo foundation for an AI-powered short-form video automation platform.

This repository provides:

- A FastAPI backend with clean architecture boundaries
- An Electron + React + TypeScript desktop application
- Docker Compose infrastructure for PostgreSQL, Redis, RabbitMQ, and Ollama
- Structured JSON logging with rotation
- Environment-based configuration
- Testing, linting, and documentation scaffolding
- Shared runtime clients, hardened health monitoring, and stricter desktop/Electron boundaries
